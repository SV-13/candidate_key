## Behaviours checked but not classified as defects

- `GET /` and `GET /favicon.ico` return `404`. These are not defects because the API contract does not require a root page or favicon; `/health` is the specified readiness endpoint.
- An early punch-in produces `late_minutes: 0`. That is expected: an employee who punches in before shift start is not late.
- `doc.pop("_id", None)` in `create_employee` is not a defect. Removing MongoDB's internal identifier from the public response is appropriate; the endpoint's public response should not expose `_id`.
- `load_dotenv()` not overriding existing environment variables is expected default behavior. Explicit environment values should continue to take precedence over `.env` values unless `override=True` is deliberately requested.
